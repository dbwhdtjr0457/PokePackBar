# 그림 가시성과 홀로 질감 균형 수정 — 2026-09-30

## 적용 내용

이전 `foil-artwork-balance-2026-09-30.md`의 과밀 질감 문제를 수정한다.
효과 전체를 원본에 흐리게 합성하는 실험용 코드를 제품에 넣지 않았다.
실제 미세 능선의 명암과 독립 반짝임을 분리하여 조정했다.

- **MUR**: 능선 명암만 기존의 44%로 줄이고 개별 반짝임의 최고 밝기,
  금색 팔레트, 능선 위치·방향·해상도는 유지했다. 어두운 사진형 원본은
  평균 휘도 0.5 미만일 때 30%를 사용한다. 리자몽 X가 이 보호를 받는다.
  평균 휘도는 기존 이미지 필드를 생성할 때 한 번 계산하고 캐시하며,
  포인터 이동마다 이미지 분석을 다시 하지 않는다.
- **SAR·풀아트**: illustration 70%, etched satin/mirage 72%로 미세 능선
  명암을 조정한다. 바깥 홀로 영역·테두리·패턴 종류는 변경하지 않았다.
- **Amazing Rare**: 원본의 컬러 스플래시와 중첩되는 미세 능선은 55%로
  조정한다. 기존 그림 기반 보호와 독립 반짝임은 그대로 유지한다.
- **석판**: stone 능선 65%. 원본 돌 무늬와 새 입자의 과도한 중첩을 줄인다.
- **복각**: microEtching 선 폭 .00115 → .00090, 명암 75%.
  금색 테두리 파편/별은 유지하고 내부 컨페티의 어두운 반사와 중간 밝기
  체류를 줄인다. 최대 반짝임은 유지한다. 파편 좌표와 독립 법선은 변경하지 않는다.
- **Cosmos/Gold Star**: 전부 낮추지 않는다. 전수 검사에서 모든 관련 판형의
  작은 각도 신호 ≥8, 큰 각도 ≥16이며 원본 대비 손실도 확인된 이미지에만
  바탕 능선 32%, 비반사 상태의 검은 fleck .88 → .22 보정을 적용한다.
  등록 원본 해시에 묶인 `foil-artwork-balance.json`으로 관리한다.
  원본이 바뀌거나 등록되지 않은 카드는 기존 응답을 유지한다.
  최종 보정은 456개 이미지다. `base5-12`는 cold run 간 배경 분할 결과가 달라
  보정 후 신호가 .91/3.55로 달랐다. 좋은 결과만 선택하지 않고 보정 목록에서
  제외해 기존 응답을 유지하며, 이 분할 안정성 문제는 별도로 남긴다.
- **BWR·Neo Shining·일반 금색·미변경 재질**: 기존 효과를 보존한다.
  MUR 보호가 일반 UR/BWR까지 전파되지 않도록 계약 검사를 추가했다.

`build_foil_balance_profile.py`는 이전 전체 검사 결과의 완전성을 확인한 뒤
보수적인 Cosmos 보정 목록을 생성한다. 이 데이터는 시각 균형 계수이며
실물 엠보싱 판형 인증이나 새 실물 홀로 영역의 등록이 아니다.

## 검사 및 변경 범위

- 도감 32,511판형의 실제 렌더 전수 재검사와 별도 기본 에너지 74판형 검사를 완료했다.
- Cosmos 완화의 1차 일괄 적용에서 약한 카드의 신호 저하를 검출했기 때문에,
  해당 시도를 최종 결과로 사용하지 않고 원본별 보정으로 좁혔다.
- 최종 Cosmos/Gold Star 재검사는 영향을 받는 **1,059판형 모두**를 대상으로 한다.
  대표 몇 장만 재검사해 전체 결과를 대체하지 않았다.
- `compare_artwork_balance.py`가 전체 키 일치, MUR의 대비 개선/효과 유지,
  BWR의 응답 보존, 비홀로 무간섭을 검사한다. 새 약한 신호 후보도 별도로 기록한다.
- MUR 외 직접 비교에는 뜨아거·리피아 SAR, N 복각, 자마젠타 AR 및 강한 Cosmos
  배경 사례가 포함된다. 전 카드의 육안 합격이나 실물 일치 인증을 주장하지 않는다.
- Python 그림 검사/회귀 비교 테스트 9개 통과. release 빌드 및 패키지의 optics,
  원본별 영역, 복각 영역, 한국어 이름, 시세, 에너지 이미지/언어 검사를 통과했다.
  XCTest 및 실시간 드래그 FPS를 측정했다는 의미는 아니다.

수치 결과는 최상위 작업 폴더의 `reports/ppb-artwork-fix-2026-09-30/`에 보존한다.

`mur-round1/`은 MUR 전체, `runtime-mur/`은 앱 캐시 확인이다.
