# 중앙 광원 자국 제거 — 2026-09-29

## 변경 목적

기존 홀로의 질감·색상·카드별 마스크는 유지하면서, 카드를 기울일 때
아트 중앙을 따라 움직이는 둥근 광원 자국을 제거한다.

## 원인과 수정

- `FoilReliefLayer`의 미세 능선은 서로 다른 법선을 갖지만 모두 같은 중앙
  가우시안 조명에 묶여 있었다. 공간상 최대 밝기를 중앙에 만드는 항을
  제거하고, 미세 면마다 고정된 위상을 갖는 각도 반응으로 교체했다.
- 코팅 및 일부 보조 반사의 광원 중심을 카드 바깥으로 이동했다.
  재질에 필요한 선형 반사 띠와 국소 문양은 유지한다.
- 이미지 기반 흑백/단색 각인은 원형 조명 대신 카드 바깥의 방향성 조명을
  사용한다. 원본에서 얻은 각인 마스크와 인쇄 잉크 제외 마스크는 유지한다.
- 카드 이미지 자체에 촬영되어 있는 하이라이트는 변경하지 않는다.

## 검증 범위

실제 앱 렌더러를 240pt 카드 크기로 실행하고, 정면·미세 움직임 4방향·
큰 움직임 5방향을 비교했다. 아래 수치는 정면 대비 RGB 변화량(0–255)의
영역 평균이며 실물 일치도 점수가 아니다.

| 카드 / 판형 | 미세 움직임 | 큰 움직임 | 판정 |
| --- | ---: | ---: | --- |
| me1-187 / gold | 6.93 | 15.25 | 가시성 기준 통과 |
| rsv10pt5-172 / blackWhite | 3.05 | 10.81 | 가시성 및 과도한 전면 변화 상한 통과 |
| sv8pt5-144 / etched | 9.47 | 17.68 | 가시성 기준 통과 |

수정 전 설치본과 같은 카드·각도로 렌더링하여 비교했다. 금색과 각인
접촉 시트 및 단색 각인 대표 프레임을 육안 확인했다. 이 검사는 모든
카드의 실물 재검증이나 모든 종류의 하이라이트 제거를 의미하지 않는다.

`--audit-foil-optics`에 광원 위치(441개 기울기), 중앙 조도 최대값 부재,
미세 면의 움직이는 반짝임 유지 검사를 추가했다. SAR 대표 카드는
`scripts/audit_foil_visibility.py`의 지속 가시성 검사에도 등록했다.

## 후속: 중앙 광원 없이 미세 질감 대비 복원

사용자 확인에서 중앙 광원 제거 후 질감이 약해 보인다는 피드백이 있었다.
기존 가시성 검사는 움직임을 검출하지만, 읽을 수 있는 미세 각인 대비를
별도로 보장하지 않았으므로 아래처럼 보완했다.

- 각인 이웃끼리 작은 범위에서 빛을 함께 받는 결정적 위상장을 추가했다.
  SAR·일반 각인·미세 각인·금색은 서로 다른 묶음 크기를 사용한다.
  먼 영역의 반응은 서로 독립적이며 색상에는 이 위상장을 적용하지 않는다.
- 밝은 능선 옆에 얇은 어두운 면을 배치하고, 작은 화면에서도 드러나도록
  능선 폭과 명암을 조정했다. 중앙 가우시안 광원과 전면 흰색 면은 복원하지 않았다.
- 기념 세트의 파편 형상·색상·반사 속도는 유지하며 그 사이 미세 각인만 보강했다.
- 고정된 면의 기하와 조명 위상은 기존 제한 크기 캐시에 저장한다.
  기울일 때 이웃 위상장을 다시 생성하지 않는다.

### 추가 비교

240pt·평면 고정 렌더의 정면 대비 변화에서 3px 이내 고주파 성분을 측정한다.
인쇄 이미지 자체의 세부와 균일한 밝기 변화는 이 측정에 포함하지 않는다.
실물 일치도나 사용자 체감 개선율을 뜻하는 수치는 아니다.

| 카드 | 기존 미세 명암 변화 | 수정 후 | 비율 |
| --- | ---: | ---: | ---: |
| me1-187 / gold | 12.002 | 15.407 | 1.284 |
| sv8pt5-144 / etched | 13.161 | 17.594 | 1.337 |
| me2pt5-295 / gold | 11.941 | 15.208 | 1.274 |

세 카드 모두 10개 각도로 렌더링하고 비교했다. `--min-texture-gain 1.10`
검사를 통과했다. 별도 대표 샘플로 cel30c-21의 파편+미세 각인을 확인했고,
rsv10pt5-172의 이미지 기반 단색 각인은 이번 수정에서 유지했다.
변화 없는 이미지·전체 밝기 변화가 미세 질감 검사로 통과하지 않는 단위
검사와, 가까운 영역만 상관되는 위상장 검사를 추가했다.

Python 가시성 검사 단위 테스트 9개와 앱 자체 `--audit-foil-optics`,
`--audit-reviewed-foil` 검사를 통과했다. Swift XCTest 실행은 로컬
Command Line Tools에서 `no such module 'XCTest'`로 중단되어 실행 완료로
간주하지 않는다. 추가로 sma-SV49·sv4pt5-232를 각각 10각도로 렌더링했다.
두 추가 카드의 오프라인 캐시는 저해상도이므로 원본 화질 평가는 제외한다.
