# 홀로 질감과 그림 가시성 전수 검사 — 2026-09-30

## 결론

현재 효과는 움직임이 잘 보이지만, 일부 재질은 그 효과가 그림보다 앞에 보인다.
특히 MUR 8장 전부에서 금색 미세 입자가 저대비 그림을 덮는 현상을 재현했다.
중앙의 큰 흰 조명보다 **넓은 면적을 동시에 차지하는 고밀도 능선 반사**가 주원인이다.

해결 방향은 전체 광량 감소가 아니라 **그림·문자 위 입자 점유율과 대비를 줄이고,
테두리·독립 반짝임은 별도 유지**하는 것이다. MUR 비교 실험에서는 현재 전체 합성
강도의 40–55%가 더 나은 출발점이었다. 이는 최종 셰이더 계수나 실물 인증 수치가 아니다.
일부 SAR/풀아트는 70% 부근, 배경 과밀 Cosmos와 Amazing Rare는 별도의 영역 조정이 필요했다.
반대로 BWR 3종은 현재 효과가 그림의 각인을 드러내므로 일괄 감쇠 대상이 아니다.

이번에는 **검사 도구와 이 보고서만 추가/수정**했다. 제품의 홀로 계수·영역·재질,
설치 앱, 세이브, 서버는 변경하지 않았다. 하단의 권고는 아직 적용되지 않았다.

## 측정 방법과 해석

일러스트 영역은 실제 이미지의 aspect-fit 내부에 `FoilGeometry.artRect`를 적용한다.
일반적인 선명도 점수는 추가한 노이즈를 좋은 디테일로 오인하므로 사용하지 않았다.
대신 원본과 같은 방향의 명암 경계를 비교한다.

- 3×3 평활화 후 강한 원본 경계(차이 ≥12/255)의 투영 대비를 측정한다.
  `edgeRetention=1`은 원본과 같은 방향의 대비, 0.8 미만은 대비 손실 후보다.
  이것은 “그림의 80%가 보인다”는 사람의 인지 비율이 아니다.
- 약한 원본 경계(3–12/255)의 상관도도 측정해 노란색 위 노란 그림 같은 MUR를 따로 잡는다.
  0.8 미만은 미세 그림과 효과 간섭 후보다. 의도한 엠보싱도 점수에 영향을 줄 수 있다.
- 원본 대비 밝기 ±35/255 변화가 그림 영역의 15%를 넘는지, 국소 경계가
  원래의 65% 미만으로 약화/역전되는지, 새 흰색 클리핑이 생기는지도 기록한다.
- 효과 가시성은 정면 대비 작은/큰 기울기의 실제 RGB 변화로 별도 측정한다.
  기존 기준은 작은 기울기 2.5/255, 큰 기울기 5/255, 변화 면적 10%다.
  작은 스탬프는 실제 모티프 범위에서 따로 검사한다. 이는 지각 보장 기준이 아닌 경고 기준이다.
- 원본 그대로의 대조군을 통과시키고 50% 흰 베일을 인위적으로 덮은 경우를 검출하는
  진단 자체 검사를 추가했다. 비홀로 12,218판형에서 그림 간섭 경고는 0개였다.

## MUR 8장: 원본·현재·감쇠 비교

전체 합성 강도 100·85·70·55·40%를 각각 10각도로 네이티브 렌더링했다.
원본 위에 **완성된 렌더 전체를 그룹 합성**한 비교이며 제품의 `opacity`를 변경하지 않았다.
글로우 등 자식 레이어를 개별 감쇠한 것이 아니며, 최종 영역별 해법을 대체하지 않는다.

### 소스에서 확인한 이유

- `FoilReliefLayer.swift`: megaGold는 가로 샘플 400, 능선 폭 .88로 일반 금색보다 촘촘하다.
- 금색 gain은 `1.22 + magnitude × 1.00`, 능선 alpha는 최대 1까지 올라간다.
  많은 능선이 동시에 강하게 반사하면 큰 조명 없이도 그림을 넓게 덮는다.
- 현재 그림 보호는 `light < .20 && edge > .40`인 어두운 강한 선 위주다.
  금색 바탕의 약한 금색 얼굴·몸통은 이 조건을 만족하지 않는다.
- 따라서 단순 검은 글자 보호만이 아니라 약한 그림 경계·실루엣을 고려해야 한다.
  이미지 기울기에서 만든 보호 마스크를 공장 엠보싱 플레이트라고 부르면 안 된다.

Cosmos는 같은 재질 안에서도 양극단이다. 일부는 배경 grain이 지나치고, 분홍장이/붐볼은
그 배경 효과가 거의 나오지 않는다. `FoilSheetLayer`는 배경 분할이 있으면 Cosmos relief를
.78, Gold Star는 .62로 추가한다. 분할이 없으면 보수적으로 바탕 효과를 생략한다.
이 때문에 “Cosmos 전체 55%” 같은 일괄 처방은 부적절하다. 강한 배경과 누락 마스크를 구분해야 한다.

## 기본 에너지 추가 발견

74판형 전부를 렌더링했고, SVE 불꽃 holo·SM 물 reverseHolo·SWSH 강철 reverseHolo·
30주년 번개 holo의 비교 이미지도 직접 확인했다.

- SVE 불꽃은 중심 그림에 변화가 거의 없고 위아래 테두리·문자 쪽 입자만 두드러진다.
- SM 물과 SWSH 강철 리버스는 같은 일반 대각선 선무늬로 보이고 움직임 변화가 작다.
- 30주년 번개는 중심 구체는 잘 남지만 배경·헤더가 과밀하다. 약 70%에서 더 정돈된다.
- `CardFinishResolver`가 ID의 첫 `-` 앞을 sourceSetID로 사용하여
  `supplement-energy-sve-fire`도 `supplement`로 처리한다. 시대별 스타일을 알고 있는
  `SupplementalEnergyCard` 정보가 재질 분기까지 전달되지 않아 일반 fallback에 들어간다.
  **라우팅 정보 손실은 확인**, 각 에너지 판형의 정확한 실물 패턴은 별도 확인이 필요하다.
- 약한 신호는 리버스 25 + SVE holo 8 = 33판형. 단순 광량 증가 전에 스타일·영역부터 고쳐야 한다.

## 수정 시 권장 순서와 수용 기준

1. **MUR 8장 우선**: 저대비 그림·얼굴·문자 위 능선의 점유율/폭/합성량을 줄인다.
   실험상 그림 위 40–55%를 출발점으로 삼되, 리자몽 X는 별도 보호와 원본 상태 검토.
   금색 팔레트와 금속 미세 구조를 유지하고, 좁은 반짝임과 테두리까지 같이 죽이지 않는다.
2. **Amazing Rare, 과밀 SAR/복각/풀아트**: AR 55–70%, 검토한 SAR 약 70%의 그림 보존을
   참고하되, 컨페티·엠보싱·테두리·각인별로 분리한다. 숫자는 선택 샘플에서 얻은 출발점이다.
3. **Cosmos 양극단**: 강한 배경 grain은 낮추고 기존 별/원형 플래시는 유지한다.
   약한 26개 Cosmos는 개별 배경 마스크부터 확인한다. 그림 전체로 홀로 영역을 늘려 통과시키지 않는다.
4. **기본 에너지 41이미지/74판형**: 실제 시대·스타일을 재질 라우팅으로 전달하고
   헤더만 반짝이거나 일반 대각선 fallback으로 끝나는 경우를 검토한다.
5. **모티프별 대비**: 강한 리버스 심볼·BREAK 격자는 선/마크 대비만 조정한다.
   BWR 및 충분히 선명한 재질은 보존한다. 밝은 Tera 등 약한 사례는 별도 강화한다.

수정 후에는 동일 입력·10각도로 전수 재검사를 한다. 효과 신호만 높아졌다고 통과시키지 않고,
MUR는 약한 그림 경계까지 확인한다. 초기 경고 기준으로 강한 경계 보존 ≥.85 및
약한 경계 상관 ≥.85를 사용할 수 있으나, 의도한 재질 구조와 직접 비교한 시각 판정을 함께 사용한다.
이 기준을 맞추려고 모든 미세 질감을 제거하거나 효과 영역을 임의 확장하면 안 된다.

## 결과 파일과 재현

로컬 전체 결과: `reports/ppb-artwork-balance-2026-09-30/` (최상위 작업 폴더 기준).

- `catalogue/per-printing.csv`: 전 32,511판형의 이름·등급·재질·상태·경고·각도·그림/효과 수치.
- `catalogue/per-material.csv`: 모든 재질의 모집단·경고·약한 신호 개수.
- `catalogue/shard-*.jsonl`: 카드별 10각도 원시 수치. `summary.json`, `provenance.json` 포함.
- `supplemental.jsonl`: 추가 74판형. `energy-visual.jsonl`: 직접 확인한 4판형 재검사.
- `runtime-cache/`: 실제 다운로드된 고화질 캐시만 사용한 1,669판형 결과.
- `mur-final-study/`, `visual-candidates/`: MUR 전체 및 추가 25판형 결과.
- `strength-studies/`: 직접 확인한 37판형의 100·85·70·55·40%별 10각도 수치.
- `visual-keys.json`, `energy-visual-keys.json`: 직접 확인한 비MUR 대상 목록.

전수 실행 예 (리포지토리 루트):

```sh
swift build -c release -j 4
python3 scripts/audit_artwork_balance.py \
  --binary .build/release/PokePackBar \
  --art-dir ../PokePackBar-upstream/local-assets/CardArt \
  --output /tmp/ppb-artwork-new-run --workers 4
```

기본 에너지는 같은 실행 파일의 `--audit-catalogue-foil OUTPUT --art-balance --supplemental`로
검사한다. `--contact-dir DIRECTORY`는 비교 이미지와 강도별 수치를 추가한다. 기존 파일은
덮어쓰지 않으며, 다른 출력 폴더를 사용해야 한다. `PPB_OFFLINE=1` 및 명시적 원본 경로를 사용한다.

진단 코드 빌드 성공, Python 진단 집계 테스트 5개 통과, native 원본/흰 베일 대조 검사 통과,
설치본 optics 계약 검사 통과, `git diff --check` 통과. XCTest·인터랙티브 FPS 검사를 실행했다는
의미는 아니다. 임시 PNG와 진단 실행 파일 사본은 검사 후 삭제하고 수치·판정 기록은 보존한다.
